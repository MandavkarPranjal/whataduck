⚡ Bang pipeline benchmark

Compares the old redirect path (pre-e919d71: full src/bang.ts bundled into main.ts, lookups via bangs.some() / bangs.find() — up to ~6 linear scans over ~13.5k entries per redirect) against the new path (codegen'd redirectMap hash lookup, O(1); full list lives in data/bangs.min.json, lazy-loaded only by /search and /blocklist, cached in IndexedDB + Service Worker, re-downloaded only when the data version changes).

Numbers below marked live are measured right now in your browser against the real data/bangs.min.json. Static sizes were measured at build time.
